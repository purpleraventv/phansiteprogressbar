## Phan-Site Versions

### phan-site-1.html

**Poll date:** 4/15  
**Question:** Do you believe in the Phantom Thieves?  
**Popularity range:** 0–10%

`phan-site-1.html` recreates the Phan-Site poll adopted on 4/15, representing a Phantom Thieves popularity level between 0% and 10%.

The displayed comments are drawn randomly from the poll's comment database and rotate every 3 seconds. The displayed popularity percentage fluctuates within the 0–10% range.
